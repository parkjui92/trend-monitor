# 점검 기록 — 예시 입력의 기대 결과

측정 방법: Chrome(헤드리스, 창 1280×720)으로 `index.html`을 파일로 직접 열고(file://) 버튼을 눌러 화면에 나온 숫자를 읽었다. 측정일 2026-10-17.
`rules.js`를 고치면 아래 숫자가 바뀐다. 고친 뒤에는 다시 재서 이 파일을 함께 고친다.

## 3. 빈 줄·날짜 없는 줄이 섞인 입력

입력(빈 줄 2개, 날짜 없는 줄 1개, 따옴표 속 쉼표·따옴표):

```
date,title,url
2026-09-01,"정부, AI 기본법 시행령 발표",https://example.com/a

,날짜가 빠진 기사,https://example.com/b
2026-09-02,오픈소스 LLM 공개,https://example.com/c
   
2026-09-03,"따옴표 ""안의"" 따옴표, 쉼표",https://example.com/d
```

결과: 총 3건 · 분류됨 2 · 미분류 1 · 건너뛴 줄 1

메시지: 3건을 읽었습니다. 빈 줄 2개는 무시했습니다. 1줄을 건너뛰었습니다: 4번째 줄 — 날짜 없음

| date | title | field | issues |
|---|---|---|---|
| 2026-09-01 | 정부, AI 기본법 시행령 발표 | 정책·규제 | (없음) |
| 2026-09-02 | 오픈소스 LLM 공개 | AI·모델 | (없음) |
| 2026-09-03 | 따옴표 "안의" 따옴표, 쉼표 | 미분류 | (없음) |

## 4. 머리줄 없는 붙여넣기 · 날짜 형식 오류

```
2026.9.4,Nvidia GPU 공급 부족,https://example.com/e
9월 5일,날짜 형식이 다른 줄,https://example.com/f
2026-02-30,없는 날짜,https://example.com/g
```

결과: 총 1건(`2026-09-04` · 반도체·하드웨어) · 건너뛴 줄 2 (2번째 줄 "9월 5일", 3번째 줄 "2026-02-30" — 날짜 형식이 아님). 첫 줄에 칸 이름이 없어 첫째 칸=날짜, 둘째 칸=제목으로 읽었다는 안내가 나옴.

빈 입력으로 「분석하기」: 모두 0, 메시지 "읽을 줄이 없습니다. …"

## 5. CSV 내보내기 → 다시 넣기

- 저장 파일: `trend-monitor_분류결과.csv` (UTF-8, BOM 포함), 첫 줄 `date,title,url,field,issues`, 기록 1,417줄
- 이 파일 내용을 입력 칸에 넣고 「분석하기」 → 총 1,417 · 분류됨 1,137 · 미분류 280 · 건너뛴 줄 0
- 다시 넣은 뒤의 기록 1,417건이 처음 결과와 모두 같음: 예

# 정책·기술 동향 모니터 (trend-monitor)

기사 목록(날짜·제목·링크)을 넣으면 분류 사전(`rules.js`)대로 분야·쟁점을 붙여 분야별 개수·주별 추이·쟁점별 목록으로 보여 주는 웹페이지.

배포 주소: https://parkjui92.github.io/trend-monitor/

## 설명영상

https://github.com/user-attachments/assets/39e75017-72c6-4a48-a55f-aa17c67bd8f7

Claude가 화면을 조작하며 예시 불러오기 → 분야별 개수 → 막대 누르기 → 쟁점 탭 → 제목 검색 → 미분류 목록 → CSV 내보내기를 차례로 보여 주는 35초 영상(소리 없음).

## 쓰는 법

1. `index.html`을 더블클릭해 브라우저로 연다. 서버·설치·인터넷 연결이 필요 없다.
2. 「예시 불러오기」를 누르면 긱뉴스 2026년 9월 목록 1,417건이 입력 칸에 들어가고 바로 분석된다.
3. 내 자료는 CSV를 입력 칸에 붙여넣고 「분석하기」(Ctrl+Enter)를 누르거나, 「파일 선택」으로 CSV 파일을 고른다.
4. 화면 보는 법
   - 요약: 총 건수 · 분류됨 · 미분류 · 건너뛴 줄
   - 분야별 개수: 막대를 누르면 주별 추이에 그 분야 선이 함께 그려진다
   - 주별 추이: 월요일에 시작하는 주 단위. 속 빈 점은 수집 기간이 7일을 다 채우지 못한 주
   - 쟁점별 목록: 쟁점 탭을 고르고, 검색 칸에 제목 낱말을 넣으면 목록이 줄어든다(대소문자 무시)
   - 미분류 목록: 어느 분야 낱말에도 걸리지 않은 기사. `rules.js`에 낱말을 더할 후보
5. 「CSV 내보내기」는 분류 결과 전체를 `date,title,url,field,issues` 칸으로 저장한다. 이 파일을 다시 넣어도 같은 결과가 나온다.

### 입력 형식

```
date,title,url
2026-09-01,기사 제목,https://example.com/article
```

- 첫 줄의 칸 이름으로 칸을 찾는다(`date`/날짜, `title`/제목, `url`/링크). 다른 칸이 더 있어도 된다.
- 첫 줄에 칸 이름이 없으면 첫째 칸=날짜, 둘째 칸=제목, 셋째 칸=링크로 읽는다.
- 쉼표가 든 제목은 따옴표로 감싼다. 예) `"정부, AI 기본법 시행령 발표"`
- 날짜는 `2026-09-01`, `2026.9.1`, `2026/09/01` 모두 읽는다.
- 빈 줄은 무시한다. 날짜가 없거나 틀린 줄, 제목이 없는 줄은 건너뛰고 몇 번째 줄인지 알린다.

## 처리 기준 (rules.js)

```js
window.RULES = {
  fields: { '정책·규제': ['정책', '규제', …], '보안·개인정보': ['보안', '취약점', …], … },
  issues: { '안전·위험': ['안전', '위험', …], '일자리·노동': ['일자리', '해고', …], … },
};
```

- 분야(`field`): 위에서부터 차례로 보고 처음 맞은 분야 하나만 붙인다. 어디에도 안 맞으면 `미분류`
- 쟁점(`issues`): 맞은 쟁점을 모두 붙인다. 하나도 없을 수 있다.
- 한글 낱말은 제목에 그 글자가 들어 있으면 일치. 영문 낱말은 대소문자를 무시하고 낱말 단위로 맞춘다(`AI`는 `Email`에 걸리지 않고, `agent`는 `agents`에도 걸린다).
- 분야 순서는 정책·규제 → 보안·개인정보 → 반도체·하드웨어 → 에이전트·개발도구 → AI·모델 → 기타 기술. 넓은 분야를 아래에 두어 좁은 분야가 먼저 잡히게 했다.
- **`rules.js`를 고치면 분류가 바뀐다.** 낱말을 더하거나 빼거나 분야 순서를 바꾼 뒤 브라우저를 새로 고침하고 다시 분석한다. 바꾼 뒤에는 `docs/checks.md`의 숫자도 다시 재서 고친다.

## 연결 약속 (A → B)

A는 처리를 끝내면 이벤트 하나를 보낸다. B는 이 이벤트만 듣는다.

```js
window.dispatchEvent(new CustomEvent('records-ready', { detail: records }));
```

`records`는 아래 모양의 기록 배열이다. 예시 입력에서 실제로 나온 한 건:

```json
{
  "date": "2026-09-27",
  "title": "OpenAI 연구원, “불법 복제 도서 사용이 Hacker News에 알려지면 곤란”",
  "url": "https://authorsguild.org/news/ag-v-openai-top-execs-knew-mass-book-piracy-was-illegal/",
  "field": "AI·모델",
  "issues": ["저작권·데이터"]
}
```

A가 끝나기 전에 B는 브라우저 콘솔(F12)에 아래를 붙여 넣어 그래프·목록을 시험한다.

```js
window.dispatchEvent(new CustomEvent('records-ready', { detail: [
  { date: '2026-09-27', title: 'OpenAI 연구원, “불법 복제 도서 사용이 Hacker News에 알려지면 곤란”',
    url: 'https://authorsguild.org/news/ag-v-openai-top-execs-knew-mass-book-piracy-was-illegal/',
    field: 'AI·모델', issues: ['저작권·데이터'] },
] }));
```

## 한계

- **낱말 일치 분류라 문맥을 못 본다.** 예시 입력에서 실제로 생긴 잘못 분류된 예:
  - '모델' → "Apple, AirPods 5 공개 - 기본 모델에도 노이즈 캔슬링 탑재"가 AI·모델
  - '정부' → "퀄컴 NPU에서 VLA 실시간 구동하기: 백본 선정부터 …"('선정부터' 속 '정부')가 정책·규제
  - '감시' → "… 실시간 폴더 감시, 자동 변환 …"이 보안·개인정보
  - 'EU' → "Statichost.eu - 100% 유럽 기반 정적 사이트 호스팅"이 정책·규제
- **분야는 첫 일치 하나만 붙는다.** "한국, 중대한 개인정보 유출에 매출 최대 10% 과징금"은 정책·규제가 먼저 맞아 보안·개인정보 개수에는 들어가지 않는다(쟁점 '개인정보'는 붙는다).
- 제목만 본다. 기사 본문은 읽지 않는다.
- 주별 추이의 첫 주(9/1\~9/6)와 마지막 주(9/28\~10/1)는 7일이 다 차지 않아 건수가 적게 보인다.
- 예시 입력은 기술 뉴스 모음이라 쟁점 낱말이 걸리는 기사가 1,417건 중 146건뿐이다.

## 예시 입력 출처

- 긱뉴스(news.hada.io) 2026년 9월 목록의 날짜·제목·원문 링크만 담았다(1,417건, 2026-09-01~2026-10-01). 기사 본문·추천 수·댓글 수는 넣지 않았다.
- 긱뉴스 자체 글(Show GN 등)은 원문 링크가 `topic?id=…`로만 적혀 있어 `https://news.hada.io/topic?id=…`로 바꿔 적었다.
- 제목과 기사의 권리는 각 원문과 긱뉴스에 있다. 수업 실습용 예시로만 쓴다.
